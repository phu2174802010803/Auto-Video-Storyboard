## 🚀 Workflow

### Basic Workflow (Fast)

1. Select **Art Style** (Pixar 3D)
2. Enter **Character Description**
3. Adjust **Sliders** (3 góc + 2 expressions)
4. Click **"Tạo Character Sheet"**
5. Wait 30-60s
6. Download result

### Advanced Workflow (Best Quality)

1. **Find/Upload Reference Image**
   - Good character sheet example
   - Clear layout
   - Desired style

2. **Select Matching Art Style**
   - If reference is Pixar → Select Pixar 3D
   - If reference is Anime → Select Anime

3. **Write Detailed Description**
   ```
   Vietnamese boy student, 12 years old,
   wearing blue and white horizontal striped t-shirt,
   navy blue denim shorts with rolled cuffs,
   tan brown backpack with yellow buckles,
   white canvas sneakers with gray soles,
   short black hair with natural texture,
   friendly warm smile showing teeth,
   bright curious brown eyes,
   healthy tanned skin tone,
   slim athletic build
   ```

4. **Match Configuration with Reference**
   - Reference có 3 full-body → Set 3
   - Reference có 2 faces → Set 2

5. **Generate & Review**
   - Check consistency
   - Check quality
   - Check layout match

6. **Iterate if Needed**
   - Try different art styles
   - Adjust description
   - Use better reference

## 💡 Pro Tips

### For Best Results

**1. Detailed Descriptions Win**
```
❌ "boy with blue shirt"
✅ "12-year-old Vietnamese boy, blue and white 
    striped t-shirt, navy shorts, brown backpack..."
```

**2. Match Style to Purpose**
- Animation → Pixar 3D or Disney 3D
- Manga/Comic → Anime or Cartoon 2D
- Game (realistic) → Realistic
- Indie Game → Stylized

**3. Use High-Quality References**
- Professional character sheets
- Clear, organized layout
- Good lighting
- Clean background

**4. Be Specific About Colors**
```
❌ "blue shirt"
✅ "blue and white horizontal striped t-shirt"
```

**5. Mention Materials**
```
✅ "denim shorts, canvas sneakers, leather backpack"
```

### Common Issues & Solutions

**Issue:** AI tạo nhiều nhân vật khác nhau
**Solution:** 
- Use reference image
- Add "EXACT SAME character" in description
- Reduced complexity (fewer views)

**Issue:** Quality không đủ cao
**Solution:**
- Select appropriate art style
- Add detail to description
- Use professional reference

**Issue:** Layout lộn xộn
**Solution:**
- Upload reference with clean layout
- Reduce number of views (5 → 3)
- Match config with reference exactly

**Issue:** Có text trong ảnh
**Solution:**
- Already fixed in prompt: "NO TEXT" rule
- Use reference without text
- Regenerate if still appears
